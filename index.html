yan-backup

A personal backup tool. It uploads backup archives from a personal server to the owner's own Google Drive. It is used by its owner only and is not offered to the public.

GOOGLE DRIVE ACCESS

The tool requests only the drive.file scope. It can see and manage only the files it has created itself, and cannot read any other file in Google Drive.

Privacy Policy

Last updated 2026-10-30

DATA ACCESSED

yan-backup can access only the backup files it has uploaded itself. It cannot read, modify or delete any other file in the user's Google Drive.

HOW DATA IS USED

The files are used solely to store and verify backups of the owner's personal server. No data is collected for analytics, advertising or any other purpose.

SHARING

No data is sold, shared with or transferred to any third party.

STORAGE AND DELETION

Backup files remain in the owner's Google Drive and can be deleted there at any time. Access can be revoked at any time at myaccount.google.com/permissions.
